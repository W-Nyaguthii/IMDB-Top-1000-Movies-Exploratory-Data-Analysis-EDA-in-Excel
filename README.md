# IMDB Top 1000 Movies – Exploratory Data Analysis (EDA) in Excel

**Author:** Primrose  
**Date:** March 2026  

## 📊 Project Overview
This is my **second Excel portfolio project**. I conducted a full Exploratory Data Analysis (EDA) on the IMDB Top 1000 Movies dataset (~1,000 titles) to understand what drives high ratings, audience engagement, runtime preferences, and box-office success.

This project builds directly on my previous **Netflix Content Analysis**, moving from high-level content trends to deeper statistical and behavioral insights.

## 🎯 EDA Skills Demonstrated
- Descriptive statistics (mean, median, standard deviation, min/max, range)
- Distributions analysis using histograms
- Correlation analysis with scatterplots
- Outlier detection using conditional formatting
- Data cleaning with Power Query
- Clear insight generation and visualization

## Key Insights

- **High Quality Standard**: Average IMDB Rating is **7.95**, with most movies tightly clustered between 7.6 – 9.3.
- **Runtime Preference**: Median runtime is **119 minutes**. The vast majority of top movies fall between 100–150 minutes — audiences clearly prefer the classic ~2-hour length.
- **Highly Skewed Popularity**: Votes and Gross revenue show strong right skew. Most movies have under 200,000 votes, while a small number of blockbusters reach millions.
- **Strong Correlations**:
  - Positive correlation between runtime and IMDB rating (longer epic films tend to score higher).
  - Strong positive correlation between number of votes and gross revenue.
- **Blockbuster Outliers**: Films like *Star Wars: The Force Awakens* ($936.7M), *Avengers: Endgame* ($858M), and *Avatar* ($760M) are extreme positive outliers that heavily skew the distributions.

**Human Behavior Angle**:  
Viewers reward **emotional depth and epic storytelling** with higher ratings, while **franchise spectacle and broad appeal** drive massive audience engagement and commercial success.

## 🛠️ Process
1. Imported and cleaned data using Power Query (converted runtime & gross to numeric)
2. Generated descriptive statistics using Data Analysis ToolPak and formulas
3. Created histograms to analyze distributions of votes and runtime
4. Built scatterplots and correlation analysis
5. Identified outliers with conditional formatting
6. Summarized findings in a clean insights sheet and one-page PDF
